## Publikasi (setelah akun GitHub dibuat)
1. Buat akun di github.com dan pilih username (username menentukan alamat situs).
2. Buat repositori baru, nama usulan: `mpi-mtk-smp-buthias-2026`.
3. Unggah seluruh isi folder ini ke repositori tersebut.
4. Aktifkan GitHub Pages (Settings > Pages, sumber: Deploy from a branch, branch main, folder /root).
5. Alamat situs menjadi: `https://<username>.github.io/mpi-mtk-smp-buthias-2026/`
